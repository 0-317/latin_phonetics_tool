О проекте

Общее описание

Это инструмент для автоматизированной обработки латинских текстов, предназначенный для помощи пользователям (особенно студентам, изучающим латынь) в понимании и освоении правил деления латинских слов на слоги и постановки ударения. Это способствует правильному чтению и глубокому пониманию классических текстов.

Версия инструмента дополнена визуальными графиками, статистикой по слогам, встроенной библиотекой классических латинских текстов и многоязычным интерфейсом (русский, китайский, английский). Добавлена подробная таблица анализа каждого слова с разбивкой на слоги, указанием открытости/закрытости и долготы/краткости слогов.

Цель исследования

Разработать автоматизированный веб-инструмент для фонетического анализа латинских текстов, полностью соответствующий классическим правилам латыни. Инструмент должен обеспечивать предобработку текста, анализ фонем, деление на слоги, маркировку многофакторных признаков, статистику по слогам и визуализацию результатов, становясь эффективным помощником в преподавании и научных исследованиях.

Основные задачи

  • Систематизировать ключевые фонетические правила классической латыни, сформировав стандартизированную логику для алгоритмизации;
  • На основе языка программирования Python реализовать следующие функции: предобработку текста, распознавание фонем, деление на слоги, определение типа и длины слогов, маркировку ударения;
  • Создать веб-архитектуру с многоязычным интерфейсом и интеграцией библиотеки классических латинских текстов;
  • Разработать модуль визуализации результатов с графическими диаграммами для представления статистических данных;
  • Провести тестирование инструмента на классических латинских текстах для проверки точности алгоритмов и оптимизации пользовательского опыта.

Инструмент реализует строгое следование классическим латинским правилам фонетики. Основные функции алгоритма:

Деление слов на слоги по классическим правилам
Определение открытых и закрытых слогов
Распознавание долгих и коротких слогов
Автоматическая маркировка ударения
Статистический анализ слогов
Обработка неразделимых согласных групп

Ключевые возможности

  • Поддержка трёх языков интерфейса: русский, китайский, английский
  • Визуализация данных в виде интерактивных диаграмм
  • Встроенная библиотека классических латинских текстов
  • Подробная таблица анализа каждого слова

About the Project

General Description

This is an automated Latin text processing tool designed to help users (especially students learning Latin) understand and master the rules of syllabification and accentuation in Latin words, enabling correct pronunciation and deep comprehension of classical texts.

This version is enhanced with visual charts, syllable statistics, an integrated library of classical Latin texts, and a trilingual interface (Russian, Chinese, English). It provides detailed analysis tables for each word, including syllable division, openness/closedness and length.

Research Goal

To develop an automated web tool for phonetic analysis of Latin texts that fully complies with classical Latin rules. The tool should provide text preprocessing, phoneme analysis, syllabification, multi-feature marking, syllable statistics, and result visualization, becoming an effective assistant for teaching and academic research.

Main Tasks

  • Systematize the key phonetic rules of classical Latin, forming standardized logic for algorithmization;
  • Implement the following functions using Python: text preprocessing, phoneme recognition, syllabification, syllable type and length determination, accent marking;
  • Create a web architecture with a multilingual interface and integration of a classical Latin text library;
  • Develop a result visualization module with graphical charts for statistical data presentation;
  • Test the tool on classical Latin texts to verify algorithm accuracy and optimize user experience.

Technology Stack

Python 3FlaskChart.js MathJaxDataTablesHTML/CSS/JS

Core Algorithm

The tool strictly follows classical Latin phonetic rules. The main functions of the algorithm include:

Word syllabification according to classical rules
Open and closed syllable identification
Long and short syllable recognition
Automatic accent marking
Multi-dimensional syllable statistics
Proper handling of inseparable consonant clusters

Key Features

  • Accurate analysis based on classical Latin rules
  • Trilingual interface support: Russian, Chinese, English
  • Interactive data visualization with charts
  • Built-in library of classical Latin texts
  • Detailed analysis table for each word
